# FlowImpact（フロー型観光経済波及効果算出シミュレーター）

**フロー型観光経済波及効果算出シミュレーター**という名前で、  
観光における周遊（相互送客）をベースにした簡易的な経済波及効果を試算できるアプリを作成しました。

📍 **Webアプリはこちら**  
https://codefornoto.github.io/flowimpact/

---

## ◆ 使い方

### ◇ 操作モード

#### ・中心拠点設定モード
新しい中心拠点（ハブ）を設定するモードです。  
イベントの効果検証にも利用できるため、任意の中心点を設定し、

- 総来場者数（特定期間）
- 平均消費単価

を入力します。

例：拠点の売上高想定が **7,000万円** の場合  
平均単価は **700円** として入力します。

---

#### ・波及地点追加モード
地図上にピンを追加し、波及先となる地点ごとに

- 相互利用率（0〜1）
- 平均消費単価

を入力します。

入力は **テキストボックス** または **スライダー** のどちらでも可能です。

⚠ 地点追加を誤った場合は、地図上のピンをクリックし、  
**削除**ボタンを押下してください。

---

## ◇ データ管理

このツールはページ更新時に入力内容がリセットされます。  
入力情報を保存したい場合は、以下の機能を利用できます。

- **JSON出力ボタン**：入力内容をJSONファイルとして保存  
- **読み込みボタン**：保存したJSONファイルを読み込み、作業を再開
